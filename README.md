# Website Ulang Tahun — Black & Pink Elegant

## Cara mengganti foto
Masukkan 6 foto ke folder `assets`, lalu beri nama:
- foto1.jpg
- foto2.jpg
- foto3.jpg
- foto4.jpg
- foto5.jpg
- foto6.jpg

## Cara menambahkan musik
Masukkan satu file MP3 ke folder `assets` dan beri nama `music.mp3`.

## Upload ke GitHub
1. Buat repository baru, misalnya `ulang-tahun`.
2. Upload `index.html`, `style.css`, `script.js`, folder `assets`, dan file lainnya.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Save, lalu tunggu GitHub membuat link website.
